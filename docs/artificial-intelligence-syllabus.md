## 1. Course Overview

This course introduces core topics in artificial intelligence, including intelligent agents, search, learning, knowledge representation, reasoning, multi-agent systems, uncertainty, and generative AI.

The lecture notes are provided as slides, but the course cannot be completed by reading the slides alone. Examples and detailed worked-out explanations are given during lectures. Students are also encouraged to read the reference books.

## 3. Syllabus Topics

The following topics are covered, not necessarily in this exact order:

- Simple intelligent agents
- Agent controller design using rules
- Supervised learning
- Genetic programming
- Large language models
- Search
- Uninformed search
- Heuristic search
- Adversarial search
- Markov decision processes
- Reinforcement learning
- Supervised, unsupervised, reinforcement, and rule-based learning
- Knowledge representation
- Reasoning
- Planning
- Multi-agent systems
- Game theory
- Auctions
- Reasoning under uncertainty
- Generative AI

## 10. EduMind Demo Notes

This course is suitable for demonstrating EduMind because it includes:

- A clear weekly topic structure
- Lecture slide materials
- Programming and written assignments
- A course project
- Concept-heavy topics such as search, MDPs, reinforcement learning, CSPs, game theory, and uncertainty
- External readings that can be used as supplementary learning sources

Potential EduMind extraction targets:

- Concepts: simple agents, A* search, hill climbing, MDP, reinforcement learning, CSP, game theory, auction, reasoning under uncertainty, LLM agents
- Course chapters: weekly lectures or syllabus topic groups
- Source documents: lecture slides, project brief, reference books, external readings
- Assessment alignment: assignments, project, and final exam
